# 운영자 환경 규칙 예시

이 파일은 예시다. 쓰려면 `data/local-rules.md`(git 제외)로 복사해 이 컴퓨터에 맞게 고친다. 하네스의 스킬·에이전트·실행 지시문은 `data/local-rules.md`가 있으면 먼저 읽고 따른다. 공개 문서의 일반 규칙과 다르면 이 파일이 우선하지만, 페르소나 금지(결과물에 페르소나를 쓰지 않음)와 사람 관문(콘셉트 선택, 레벨 5 계획 검수, 제출 승인)은 바꿀 수 없다.

개인정보 값(이름, 연락처, 계정 비밀번호, API 키)은 여기에도 쓰지 않는다. 사용자 정보는 `data/profile.md`(`harness profile`로 읽는다), 비밀 값은 각 도구의 자격 증명 저장소에 둔다.

## 계산 장비

- 원격 GPU 서버: [이름, 접속 방법(예: `ssh <호스트>`), GPU, 작업 폴더, 사용 전 읽을 안내]
- 클라우드 GPU: [서비스, 계정에서 쓸 수 있는 인스턴스, 비용 상한]. 작업이 끝나면 바로 인스턴스를 삭제하고 삭제 시각을 LEDGER `notes`에 적는다.
- 작업 맥에서 꼭 돌려야 하는 무거운 작업(음악 생성, 음성 인식, 큰 ffmpeg, 영상 렌더): [감싸는 스크립트나 동시 실행 제한]

## 공유 자원 잠금

- 여러 세션이 함께 쓰는 GUI 자원(브라우저 로그인 창, 이미지·음악 생성 서비스 계정): [잠금 스크립트와 사용법, 예: `<잠금 스크립트> acquire <이름>` → 작업 → `<잠금 스크립트> release <이름>`]

## 서식·문서 도구

- HWP/HWPX: [채우기·빌드·형식 점검 스크립트 경로, 한컴독스 웹을 여닫는 스크립트와 PDF 변환 스크립트]
- 브라우저: [자동화에 쓸 브라우저, 쓰지 않을 브라우저]

## 유형별 개인 플레이북과 선례

- 숏폼·AI 영상: [개인 플레이북 경로, 선례 공모전 폴더]
- 논문: [연구 도구, 집필 도구, 이전 논문 선례 폴더, 이전 지적 사항 파일]
- 연구형·모델 대회: [선례 폴더]

## 모델 프리셋

- omp `preset_by_level`에 쓸 프리셋 이름과 그 정의 위치(`~/.omp/agent/config.yml`의 `modelPresets`). 실제 값은 `data/config.json`에 둔다.
