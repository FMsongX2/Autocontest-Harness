# 참가자 프로필

이 파일을 `data/profile.md`로 복사해 직접 채운다. `data/profile.md`는 git에 들어가지 않고 이 컴퓨터에만 있다. 하네스는 이 파일을 읽기만 하고 고치지 않는다.

- `## 참가 자격`: 게이트(ContestGate)가 참가 자격을 판정할 때 이 절만 읽는다(`harness profile eligibility`). 이름·전화번호·이메일 같은 식별 값은 여기에 쓰지 않는다.
- `## 제출용 개인정보`: 사용자가 제출을 승인한 뒤 제출 단계에서만 읽는다(`harness profile show`).
- 모르는 값은 비워 둔다. 게이트는 판정에 꼭 필요한 빈 값을 사용자에게 묻는 질문으로 남긴다.
- 영어로 쓰려면 절 제목을 `## Eligibility`, `## Submission details`로 쓴다.
